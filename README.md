# نظام النداء الصوتي المتقدم لمرضى المختبرات الطبية (LIS Patient Voice Announcer Pro)

نسخة احترافية متكاملة مخصصة للمختبرات الطبية ومراكز التحاليل، تعمل في الخلفية على بيئة ويندوز (Windows 10 / 11) وتتكامل تلقائياً مع أي نظام مختبرات مغلق المصدر (Closed-source LIS).

---

## 🌟 أبرز الميزات والتحسينات المضافة (New Enterprise Features)

1. **محرك أصوات بشرية طبيعية (Neural Arabic TTS Engine)**:
   - دعم محرك **Edge Neural Voices** فائق النقاء والطبيعية (مثل صوت *حامد* وصوت *سلمى*)، مع التحول التلقائي لمحرك **Windows SAPI5** بدون إنترنت في حال انقطاع الشبكة.
   - نظام كاش مؤقت للأصوات لضمان سرعة استجابة فورية دون أي تأخير عند تكرار النداء.

2. **الفلترة الذكية للأسماء (Smart Name & Regex Extraction)**:
   - في حال حدد موظف المختبر سطر العينة كاملاً بالخطأ (مثل: `10482 | أحمد عبد الله محمد | 34Y | CBC`)، يقوم النظام تلقائياً بتنظيف الأرقام، الأعمار، والرموز والباركود واستخراج الاسم العربي فقط.

3. **توجيه المريض لرقم الكابينة / الغرفة (Station & Room Routing)**:
   - قائمة سريعة لاختيار الوجهة:
     - *"كابينة سحب الدم رقم 1"*
     - *"كابينة سحب الدم رقم 2"*
     - *"شباك تسليم النتائج"*
     - *"الاستقبال الرئيسي"*
   - تصبح صيغة النداء: `"المريض أحمد عبد الله، يرجى التوجه إلى كابينة سحب الدم رقم 1"`.

4. **تكرار النداء تلقائياً مرتين (Double Call Option)**:
   - خيار لتكرار النداء للمريض تلقائياً بعد فاصل زمني (2.5 ثانية) لضمان سماعه في الصالة المزدحمة.

5. **شاشة عرض صالة الانتظار للتلفاز (Waiting Room TV Display)**:
   - نافذة مخصصة مستقلة يمكن سحبها إلى شاشة التلفاز في صالة الانتظار، تعرض اسم المريض الحالي بخط عريض مع رقم الكابينة وقائمة بآخر المرضى الذين تم النداء عليهم.

6. **تصدير السجل اليومي إلى Excel / CSV**:
   - زر لتصدير قائمة المرضى المنادى عليهم مع التوقيت الدقيق ورقم الكابينة إلى ملف CSV لحساب أوقات الانتظار والتدقيق.

7. **حفظ الإعدادات تلقائياً (Persistent JSON Config)**:
   - يتم حفظ مفتاح الاختصار، سرعة الصوت، الكابينة، والمحرك في ملف `lis_config.json` لتبقى محفوظة دائماً عند إعادة تشغيل البرنامج.

8. **التشغيل التلقائي مع إقلاع ويندوز (Windows Startup Registry)**:
   - خيار لتسجيل التطبيق ليعمل في الخلفية تلقائياً عند تشغيل جهاز الكمبيوتر.

## 🚀 طريقة التثبيت والتشغيل (Installation)

### 1. تثبيت المتطلبات (Requirements)
افتح موجه الأوامر (CMD) أو PowerShell في مجلد المشروع:

```bash
pip install -r requirements.txt
```

### 2. التشغيل بصلاحيات مسؤول (Run as Administrator)
أنظمة المختبرات الطبية عادة ما تعمل بصلاحيات مرتفعة، لذا يلزم تشغيل الأداة كمسؤول ليتمكن مفتاح الاختصار (`Ctrl+F1`) من نسخ الاسم المحدد:

```cmd
python patient_announcer.py
```

أو عبر اختصار سطح المكتب:
1. انقر بزر الفأرة الأيمن على سطح المكتب ➔ **New** ➔ **Shortcut**.
2. اكتب المسار: `pythonw.exe "C:\path\to\patient_announcer.py"`
3. من الخصائص (Properties) ➔ خيارات متقدمة (Advanced) ➔ فعّل **Run as administrator**.

## 📦 تحويل البرنامج إلى ملف تنفيذي مستقل (`.exe`)

لإنتاج ملف تنفيذي جاهز يعمل على جميع حواسيب المختبر دون الحاجة لتثبيت بايثون:

```bash
pyinstaller --noconsole --onefile --uac-admin --name "LIS_Patient_Announcer_Pro" patient_announcer.py
```

الملف الناتج سيكون متاحاً داخل مجلد:
```
dist\LIS_Patient_Announcer_Pro.exe
```
يمكن نقله واستخدامه مباشرة في أي مختبر طبي بنقرة واحدة!
